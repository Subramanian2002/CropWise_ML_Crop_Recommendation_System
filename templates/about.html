Our Mission

CropWise is a mini-project developed by an MCA student at SRM College. Our mission is to bridge the gap between traditional farming and modern technology. By leveraging a machine learning model, we provide farmers with reliable and scientific crop recommendations, helping them maximize their yield and profitability.

This system analyzes key environmental factors—such as soil nutrient levels (Nitrogen, Phosphorus, Potassium), temperature, humidity, pH, and rainfall—to predict the most suitable crop for a given piece of land.

Technology Stack

This project is built using a combination of web technologies and data science principles:

  • Front-End: HTML, CSS, JavaScript with the Bootstrap 5 framework for a responsive user interface.
  • Back-End: Python with Flask (or Django) to serve the machine learning model.
  • Machine Learning: A classification model (e.g., Random Forest, SVM) trained on a comprehensive agricultural dataset.
